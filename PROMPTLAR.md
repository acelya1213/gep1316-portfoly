
# GEP1316 - Yapay Zekâ Prompt Günlüğü

## Kullanılan Yapay Zekâ Aracı
ChatGPT (OpenAI)

## Prompt Günlüğü

| İstemim | YZ ne yaptı? | Ben ne yaptım? |
|---|---|---|
| GitHub'da README.md dosyasını nasıl oluşturabilirim? | Dosya oluşturma ve kaydetme adımlarını açıkladı. | GitHub depomu oluşturdum ve README dosyamı ekledim. |
| Kullanıcının adını ve doğum yılını alarak yaşını hesaplayan Python programı yaz. | Python kodunu hazırladı ve yorum satırlarıyla açıkladı. | Kodu merhaba.py dosyasına ekledim ve Terminal'de çalıştırdım. |
| Gelecekteki doğum yıllarını nasıl kontrol edebilirim? | if koşulunun nasıl kullanılacağını açıkladı. | Doğum yılı kontrolünü koduma ekledim ve değişikliği GitHub'a kaydettim. |
| Python programını MacBook'ta nasıl çalıştırabilirim? | Terminal komutlarını açıkladı. | Dosyayı indirip programı çalıştırdım ve çıktısını kontrol ettim. |

## Kendi Yaptığım Değişiklik

Python programıma gelecekteki doğum yıllarını kontrol eden bir koşul ekledim.

Bu değişiklik sayesinde kullanıcı güncel yıldan büyük bir doğum yılı girerse program hata mesajı verir ve durur.

Bu işlemde Python'un if koşulunu kullandım.

## Yapay Zekâ Kullanım Beyanı

Bu ödevde ChatGPT'den README düzenleme, Python kodu oluşturma, GitHub kullanımı ve hata çözme konularında destek aldım.

Yapay zekânın önerilerini inceleyerek dosyaları GitHub'a ekledim, Python programını çalıştırdım ve sonuçlarını kontrol ettim.
